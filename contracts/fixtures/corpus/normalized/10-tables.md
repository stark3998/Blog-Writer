Alignment is kept per column:

| Left | Center | Right | Default |
| :--- | :---: | ---: | --- |

Pipes inside cells are always escaped, in code too:

| Expression | Meaning |
| --- | --- |
| `a \| b` | logical or, with an escaped pipe in code |
| `x \|\| y` | two pipes inside code |
| a \| b | an escaped pipe in plain text |
| [link](https://example.com) | a link in a cell |
| | an empty first cell |
