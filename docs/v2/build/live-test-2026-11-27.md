provider now re-sends once with the schema in the prompt and the router validates the reply.

## Defects found live and fixed
1. Claude structured output: grammar too large (above).
2. Posts stranded in `generating` when a provider rejected the request: now `needs_attention`.
3. Superseded quarantined jobs stayed on Today: cancelling a quarantined job dismisses it.
4. Snapshot builds excluded `server/src/blogwriter/backups` (an unanchored `backups` exclude);
   the deploy rolled back automatically (the old revision kept serving).
5. Backup lifecycle prefix did not match the dated dump layout.
