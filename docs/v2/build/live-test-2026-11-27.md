## Defects found live and fixed
1. Claude structured output: grammar too large (above).
2. Posts stranded in `generating` when a provider rejected the request: now `needs_attention`.
3. Superseded quarantined jobs stayed on Today: cancelling a quarantined job dismisses it.
4. Snapshot builds excluded `server/src/blogwriter/backups` (an unanchored `backups` exclude);
   the deploy rolled back automatically (the old revision kept serving).
5. Backup lifecycle prefix did not match the dated dump layout.
6. Every browser write (POST/PUT/DELETE) got 403 from Easy Auth (sub-status 60): its CSRF
   mitigation rejects cookie-authenticated browser POSTs whose Origin is in neither the allowed
   external redirect URLs nor CORS. The bearer-token smoke tests never hit it. Fixed by listing
   the app's own origins in `login.allowedExternalRedirectUrls` (`infra/v2/easyauth.tf`); the
   app's own CSRF rule still applies. Easy Auth's sidecar logs (container `http-auth`) show
   these refusals; the app's logs never see them.
