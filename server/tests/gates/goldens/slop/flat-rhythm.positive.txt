Identity teams should review every application before the migration starts. The review should cover provisioning, groups, roles and conditional access. Each application owner should sign off on the test plan early. The migration team should schedule waves of about two hundred applications. Every wave should include a rollback plan and a named owner. Help desk staff should receive a short briefing before each wave. Monitoring should cover sign-in failures and provisioning errors daily. The project should close with a review of lessons learned.
